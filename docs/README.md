# Documentation

Study notes, chapter summaries, and diagrams for *C++ Concurrency in Action*
belong here. Per-topic `README.md` files under `topics/` document the individual
exercises; this directory is for material that spans topics.

## Guides

- [`adding-content.md`](adding-content.md) — how to add a new example or a new
  topic: the `meson.build` wiring, README templates, a naming table, a
  validation checklist, and troubleshooting.

## Suggested contents as the repository grows

- `chapters/` — one summary per book chapter
- `diagrams/` — thread/timeline diagrams and data-structure sketches
- `notes/` — investigations, benchmarks, and gotchas (e.g. false sharing,
  missed wakeups)
